# LaCare — Лендинг для салона красоты

Готовый одностраничный сайт для nail-студии или салона красоты. Чистый HTML/CSS/JS без фреймворков — легко адаптируется под любого клиента.

## Демо

[Открыть сайт](https://jane-547.github.io/nail_landing/)

## Что входит

- **Hero** — заголовок, слоган, кнопка записи
- **Услуги** — 6 карточек с ценами, выделение хита
- **Портфолио** — сетка работ (замените на реальные фото)
- **О студии** — преимущества + статистика
- **Отзывы** — 3 карточки клиентов
- **Форма записи** — имя, телефон, услуга, дата, комментарий
- Адаптивная верстка (мобильные, планшеты, десктоп)
- Плавная прокрутка и анимации появления

## 🔐 Безопасность

### Форма записи — без рисков утечки данных

- Форма **демонстрационная**: `submit` обрабатывается на клиенте (показывает окно подтверждения) и **ничего не отправляет на сервер** — персональные данные клиентов никуда не передаются и не хранятся
- Обязательные поля помечены `required` — непустая валидация на уровне браузера

### Защита от XSS и CSRF

- **Никакого `innerHTML` с пользовательским вводом** — весь JS работает только с классами и стилями (`script.js`), данные в DOM не вставляются, поэтому вектор хранимого/отражённого XSS отсутствует
- Форма не использует cookies/сессии и не совершает state-changing запросов — **CSRF-поверхности нет**

### HTTPS и целостность

- Сайт раздаётся через **GitHub Pages с HTTPS** — трафик шифрован по умолчанию
- Ноль зависимостей и внешних скриптов — нет риска компрометации через сторонний CDN (нет supply-chain вектора)

## Стек

Чистый HTML5 + CSS3 + Vanilla JS. Никаких зависимостей — открывается любым браузером.

## Как адаптировать под клиента

| Что менять | Где |
|---|---|
| Название студии | `index.html` — логотип и заголовок |
| Услуги и цены | `index.html` — секция `#services` |
| Контакты и адрес | `index.html` — секция `#booking` |
| Цветовая схема | `style.css` — переменные `:root` |
| Фото работ | `index.html` — секция `#works`, заменить `.work-item` на `<img>` |
| Отзывы | `index.html` — секция `#reviews` |

## Цветовая схема

```css
:root {
  --pink: #e8a0b0;       /* акцентный розовый */
  --pink-light: #fdf0f3; /* светлый фон */
  --dark: #1a1a2e;       /* тёмный текст и кнопки */
}
```

Меняется в одном месте — перекрашивает весь сайт.
